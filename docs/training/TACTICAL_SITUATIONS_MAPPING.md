# Team Training: curriculum to tactical situation mapping

Generated from `src/game/training12/situations/` (model `ts-1`). Do not edit by hand: run `UPDATE_MAPPING=1 npx vitest run tests/training12-situations-library.test.ts`.

**Review only, never scored.** These ts-1 situations are earlier proposals written by Devin, not approved library content. Scored Team Training is gated on Tactical Library v1: see `docs/training/library-v1/SESSION_MAPPING.md` and `REVIEW_SHEET.md`.

## Sources

- Situations: `research/logic/v0.5/data/scenario_catalog.json` (40 seeds; the v0.2 copy is identical). Every seed is `draft_seed`, `production_enabled: false`, `not_calibrated`, with no source ids.
- Selected seeds: `docs/training/v1.2/references/selected_tactical_seeds.json` (17, marked * below).
- Roles and interactions: `docs/training/v1.2/references/SoccerMaster_9v9_Roles_Interactions_Review_v0.3.md`.
- Schedule: `season-sessions.json` in `docs/training/v1.2/SoccerMaster_Team_Training_Fixed_v1.2.zip` (108 sessions, a family per role route).

## What the library does not contain

No seed has coordinates, player counts, rosters, timing, a passage of play, outcome branches or AI responsibilities. Those are authored here from the seed text and the roles review, and are **authored prototype data, not calibrated or validated**. The catalog cue and counter texts are quoted verbatim as what each variant teaches.
