## Validation boundary

Automated checks verify coverage, actor IDs, nine-slot roster limits, no GK learner, source references, field/camera coordinates, all choices/feedback, changed preferred choices, all288SVGs and their image links. Twelve intentionally corrupted inputs must fail. Results are in validation_results.json.

Editorial review checked the brief-to-cue relationship and corrected conditional contests/shots that were previously too broadly acceptable. A misread action does not receive an invented successful animation. Preferred and acceptable options remain distinct; neither is guaranteed to succeed in football.

Not validated: calibrated ball travel, interception timing, physical body orientation, omitted actors outside the short fragment, dynamic offside at pass contact, sprite animation cycles, real-device phone rendering or independent coach approval. These remain release gates, not completed certifications. Every record remains a review candidate with no reward/attribute effect.

`python3 reference_grader.py` runs the self-contained review lookup tests. Scripts in build_scripts are authoring provenance using the original workspace paths, not an installable game project. For offside implementation, check the applicable competition profile and IFAB Law11: https://www.theifab.com/laws/latest/offside/ . Runner endpoints alone cannot determine an offence; the pass moment and involvement matter.

## How to review

Read SCENE_REVIEW.md beside the art. For each state inspect pressure, support, space, reachable ball, runner timing and alternatives. Sign off only after rendered cues match the answer rationale. Wrong/unsafe options currently pause for explanation; they do not supply full animated failure paths. Preferred branches show illustrative endpoints and movement trails, not continuous simulation.
