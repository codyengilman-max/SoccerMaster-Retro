# Provenance
Original approved cutscene masters were generated with the built-in image generation tool in this project and approved by the owner. This package preserves their bytes. New assets were generated by identity-preserving costume edits or style-referenced new-character/background generation. No third-party character sprites, Disney assets, Retro Goal sprites or licensed club logos were copied into this pack. This is an asset provenance statement, not a legal exclusivity warranty.

Base generation brief: original flat 2D lightly pixelated adventure cutscene art, visible crisp square clusters, restrained warm colors, simple cel shadow shapes, no 3D/painterly texture. Preserve identity and clothing when making variants. Transparent isolated portraits, no baked dialogue/name/UI. Backgrounds leave foreground space for dialogue and character layers.

Costume prompts: same reference face, eyes, age, skin, hairstyle, head angle and body proportions; change only clothing. Home orange/cream ringer tee; training navy/orange/cream kit for demo home group and cream/navy for demo rival group; match orange/cream home group and navy/cream rival group. No numbers/logos; team assignments must be mapped to actual data.

New cast design prompts: Alex copper curls and orange/cream polo; Sam black side fringe and teal/cream tee with denim overshirt; Riley brown curly ponytail and burgundy/cream cardigan; Coach Code adult salt-and-pepper curls, moustache and navy/orange tracksuit; caregiver chestnut waves and sage pullover; original clownfish without human limbs or clothing.

Background prompts: approved Scottsdale school courtyard style extended to modest bedroom with desk/aquarium, practice touchline with cones/goal, and youth match sideline with small bleachers. Not production stadium geometry.

Gameplay source: procedural Canvas2D artwork from the approved Sprite Lab. `sprite-factory.mjs` is an extracted bounded visual factory with validated inputs. It is not an AI-generated animation atlas or a complete soccer engine.
